# Slidey Draft — Claude Code Instructions

## CRITICAL: Shell Environment
This project runs on **Windows PowerShell**. 
- NEVER use `&&` to chain commands. It is not valid in PowerShell.
- Use `;` (semicolon) to chain commands instead.
- Example: `cd C:\Users\brian\projects\slidey-draft ; npm run dev`
- This applies to ALL commands, prompts, scripts, and instructions.
